# 草原の覇者 〜ユーラシア戦記〜

12世紀末のユーラシアを舞台にした、ブラウザで遊べる3D歴史シミュレーションゲームです。
PC版『蒼き狼と白き牝鹿IV』のような遊び（勢力を選び、箱庭で内政し、合戦で領土を広げる）を、Three.js を使って現代のブラウザ向けに作り直した**ファン制作のオリジナル作品**です。

- 画像・3Dモデル・音楽・効果音は、元作品の素材を一切使っていません。すべてプログラムで生成しています（ローポリモデルはプリミティブの組み合わせ、音楽は WebAudio による自作曲の合成）。
- 登場する人物・地名は史実にもとづいています。能力値はゲーム用の創作です。

## 遊び方

```bash
npm install
npm run dev      # 開発サーバー（http://localhost:5173）
npm run build    # dist/ に静的ファイルを出力
npm test         # ゲームロジックのテスト（vitest）
```

`dist/` は静的ファイルだけなので、GitHub Pages などにそのまま置けます（`.github/workflows/deploy.yml` 参照）。

### ゲームの流れ

1. タイトルで「新しく始める」→ 地図をクリックして勢力を選ぶ（おすすめ：キヤト＝テムジン）。
2. 1ターン＝1季節。地方を選んで命令を出し、「ターン終了」で他の勢力が動きます。
3. 全53地方の75%（40地方）を支配すれば勝利。自勢力が滅べば敗北。

### 箱庭内政

各都市は 9×9 マスの箱庭です。マスには草地・砂地・丘・森・川があり、建てられる建物や効果が変わります。

| 建物 | 効果 | 配置のコツ |
| --- | --- | --- |
| 農地 | 食糧（秋に大収穫） | 川沿いで +50%、砂地は半減 |
| 牧場 | 馬・少量の食糧 | 草原の地方ほど効果大 |
| 住居 | 人口上限 | 寺院の隣で +25% |
| 市場 | 金 | 隣の住居1つにつき +15% |
| 工房 | 金・新兵の訓練度、攻城兵 | 鉱山の隣で +50% |
| 兵舎 | 徴兵上限・駐屯兵の訓練 | |
| 寺院 | 民忠 | |
| 鉱山 | 金（丘のみ） | |
| 伐採所 | 建設速度（森のみ） | |
| 隊商宿 | 交易の金（特産品の価値が加算） | |

建物は Lv3 まで強化でき、城壁（柵→土塁→石壁）は合戦での守りを固めます。森は「開墾」で草地にできます。都市を「委任」すると毎季自動で開発されます。

### 軍事

- 武将ごとに兵を率います（上限は統率×30）。兵種は騎兵・弓騎兵・歩兵・弓兵・攻城兵。騎兵系には馬が必要です。
- 隣の地方へ出陣すると、ヘックスの戦場で合戦になります。自ら指揮するか自動で戦うかを選べます。
  - 騎兵は2マス以上動いてから攻撃すると突撃ボーナス、敵を囲むと挟撃ボーナス。
  - 丘・森・城は防御に有利。攻撃側は20ターン以内に敵を全滅させるか本丸を占拠すれば勝利。
- 捕らえた武将は登用・解放・処断を選べます。

### 人事・外交

太守の政治力で産出と建設速度が、魅力で民忠が上がります。在野の人材の登用や人材探索もできます。
贈物で友好度を上げ、同盟・停戦を結べます。武将は年を取り、やがて世を去ります（15歳で元服して出仕）。

## 構成

```
src/
  game/      ゲームロジック（描画から独立・テスト可能）
    data.js      地方・勢力・武将・建物・兵種の定義
    geo.js       地図の投影、ボロノイ分割による地方領域・隣接・標高
    state.js     新規ゲーム生成と共通ヘルパー、セーブ／ロード
    city.js      箱庭（都市グリッド・建設・産出計算・AIの都市開発）
    battle.js    ヘックス戦術戦闘エンジン（AIも同じ規則で戦う）
    military.js  徴兵・占領・戦後処理・捕虜・継承・滅亡
    diplomacy.js 贈物・同盟・停戦
    ai.js        勢力AI（内政・徴兵・侵攻・増援）
    turn.js      ターン進行・季節の経済・年次イベント・勝敗判定
  render/    Three.js の描画（世界地図・箱庭・合戦・ローポリモデル）
  audio/     WebAudio による手続き生成の音楽・効果音
  ui/        HTML オーバーレイの UI とダイアログ
tests/       vitest によるロジックのテスト（60ターンの全自動シミュレーションを含む）
```

セーブデータはブラウザの localStorage に保存されます（毎ターン自動保存＋3スロット）。
