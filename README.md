# 草原の覇者 〜ユーラシア戦記〜

12世紀末のユーラシアを舞台にした、ブラウザで遊べる3D歴史シミュレーションゲームです。
PC版『蒼き狼と白き牝鹿IV』のような遊び（勢力を選び、箱庭で内政し、合戦で領土を広げる）を、Three.js を使って現代のブラウザ向けに作り直した**ファン制作のオリジナル作品**です。

- 画像・3Dモデル・音楽・効果音は、元作品の素材を一切使っていません。すべてプログラムで生成しています（ローポリモデルはプリミティブの組み合わせ、音楽は WebAudio による自作曲の合成）。
- 登場する人物・地名は史実にもとづいています。能力値はゲーム用の創作です。

## 遊び方

```bash
npm install
npm run dev      # 開発サーバー（http://localhost:5173）
npm run build    # dist/ に静的ファイルを出力
npm test         # ゲームロジックのテスト（vitest）
```

`dist/` は静的ファイルだけなので、GitHub Pages などにそのまま置けます（`.github/workflows/deploy.yml` 参照）。

### ゲームの流れ

1. タイトルで「新しく始める」→ シナリオを選ぶ → 地図をクリックして勢力を選ぶ。
2. 1ターン＝1季節。地方を選んで命令を出し、「ターン終了」で他の勢力が動きます。
3. 全53地方の75%（40地方）を支配すれば勝利。自勢力が滅べば敗北。

### シナリオ

| 開始年 | タイトル | 内容 |
| --- | --- | --- |
| 1189 | 蒼き狼の目覚め | モンゴル高原は諸部族が割拠。キヤトのテムジンが小勢力から身を起こす（35勢力） |
| 1206 | 大モンゴル国の成立 | チンギス・カン即位。南宋の北伐、デリー・スルターン朝とラテン帝国の成立（30勢力） |
| 1219 | 西方大遠征 | 中都と西遼を制したモンゴル帝国と、ホラズム・シャー朝が東西で対峙する（26勢力） |

シナリオごとに版図・君主・所属・外交関係が変わり、開始年より前に世を去った人物は登場しません（`src/game/scenarios.js`）。

### 史実イベント

条件がそろうと史実の出来事が一度だけ起こります（`src/game/events.js`）。自勢力が当事者なら選択肢から対応を選び、他勢力は史実どおりに動きます。大きな出来事は当事者でなくても知らせが届き、「勢力」→「年表」で振り返れます。設定でオフにもできます。

奥州合戦／赤髭王の最期／第3回十字軍／サラーフッディーン逝く／崔忠献の政変／頼朝の落馬／クリルタイ（大ハーンの即位）／第4回十字軍（ラテン帝国の成立）／奴隷王朝の成立／開禧用兵／天山ウイグルの帰順／貞祐の南遷／耶律楚材の出仕／オトラル事件／大憲章／承久の乱／大ハーン崩御

史実の死去イベントはAI勢力にだけ起こり、プレイヤーの人物が台本で死ぬことはありません。イベントは開始年・生存者・領有・隣接などの条件で判定するので、歴史が変わっていれば起こらなかったり、別の人物が主役になったりします（例：ジャムカが高原を統一すれば「ジャムカ・カン」が即位）。

### 箱庭内政

各都市は 9×9 マスの箱庭です。マスには草地・砂地・丘・森・川があり、建てられる建物や効果が変わります。

| 建物 | 効果 | 配置のコツ |
| --- | --- | --- |
| 農地 | 食糧（秋に大収穫） | 川沿いで +50%、砂地は半減 |
| 牧場 | 馬・少量の食糧 | 草原の地方ほど効果大 |
| 住居 | 人口上限 | 寺院の隣で +25% |
| 市場 | 金 | 隣の住居1つにつき +15% |
| 工房 | 金・新兵の訓練度、攻城兵 | 鉱山の隣で +50% |
| 兵舎 | 徴兵上限・駐屯兵の訓練 | |
| 寺院 | 民忠 | |
| 鉱山 | 金（丘のみ） | |
| 伐採所 | 建設速度（森のみ） | |
| 隊商宿 | 交易の金（特産品の価値が加算） | |

建物は Lv3 まで強化でき、城壁（柵→土塁→石壁）は合戦での守りを固めます。森は「開墾」で草地にできます。都市を「委任」すると毎季自動で開発され、税率と内政命令も自動で行われます。

### 税率・治安・内政命令（`src/game/admin.js`）

- **税率**：都市ごとに軽税（税収60%・民忠+10・人口が増えやすい）／普通／重税（140%・民忠-10）／苛税（180%・民忠-22・治安-12・人口が伸びにくい）を選べます。
- **治安**：駐屯兵・兵舎・太守の武力・民忠・税率で目標値が決まり、毎季近づきます。治安は金の収入を×0.85〜1.1で左右し、30未満で盗賊が金を奪い、低いと反乱も起きやすくなります。征服直後は30まで下がります。
- **内政命令**：都市にいる武将に命令します。命じた武将はその季節は出陣できず、各命令は1都市1季1回。使った能力が少しずつ伸びます。

| 命令 | 能力 | 費用 | 効果 |
| --- | --- | --- | --- |
| 施し | 魅力 | 食糧 | 民忠が上がり、1年間は民忠の目標+5 |
| 巡察 | 武力 | 50金 | 治安が上がる（兵を率いていると効果大） |
| 治水 | 政治 | 150金〜 | 食糧が最大+25%、夏の洪水（食糧・人口・川沿いの農地を失う）が起きにくくなる |
| 商業振興 | 政治 | 150金〜 | 金の収入が最大+25% |
| 寺社保護 | 魅力 | 200金〜 | 2年間、民忠の目標+6で異教の不満も消える |
| 布教 | 政治 | 300金〜 | 民忠-8。成功すれば地方の信仰が国教に変わる |

- **信仰と文化**：地方ごとに信仰（テングリ信仰・景教・仏教・イスラーム・カトリック・正教・ヒンドゥー教）と文化があります。国教と違う信仰の地を治めると民忠の目標が-10（テングリ信仰の国は寛容で不満が出ず、布教もしません）。征服したばかりの異民族の地は最大-6で、年とともに薄れます。
- 治水が進むと箱庭の川に石の堤が、商業が栄えると宮殿のまわりに露店が並びます。AIの国も手の空いた武将で内政を行います。

### 軍事

- 武将ごとに兵を率います（上限は統率×30）。兵種は騎兵・弓騎兵・歩兵・弓兵・攻城兵。騎兵系には馬が必要です。
- 隣の地方へ出陣すると、ヘックスの戦場で合戦になります。自ら指揮するか自動で戦うかを選べます。
  - 騎兵は2マス以上動いてから攻撃すると突撃ボーナス、敵を囲むと挟撃ボーナス。
  - 丘・森・城は防御に有利。攻撃側は20ターン以内に敵を全滅させるか本丸を占拠すれば勝利。
- 捕らえた武将は登用・解放・処断を選べます。

### 軍事の拡張（`src/game/warfare.js`）

- **固有兵種**（兵舎が必要）：ケシク（モンゴル・親衛騎兵・開戦時の士気+10）、マムルーク（イスラーム・テュルク・重装騎射兵・白兵にも強い）、騎士（西欧・グルジア・ギリシア・スラヴ・突撃×1.5）、武士（日本・騎射武者・一騎討ち+5）、弩兵（漢・高麗・チベット・雨や城壁で威力が落ちにくい）、象兵（インド・騎馬を怯えさせる）。合戦では専用の姿で描かれます。
- **陣形**：合戦の前に魚鱗・鶴翼・鋒矢・方円・長蛇から選びます。敵の陣形は軍師がいれば事前に探れます。AIは状況に応じて選びます。
- **遠征**：自領を通って2地方先（騎馬だけの軍なら3地方先）まで一度に進み、攻め込めます。
- **渡海**：海峡（イングランド〜フランス、高麗〜九州〜畿内）は冬は渡れず、渡海して攻めると上陸直後で士気が落ち、嵐で兵を失うこともあります。
- **補給線**：首都から自領（と同盟国・従属国の領地）を伝ってたどれない地方は補給が断たれ、収入が半減し、駐屯兵が毎季消耗します。
- **疲労**：合戦（+20）や行軍で疲労がたまり、士気と攻撃力が落ちます。動かずに休めば毎季20回復します。
- **傭兵**：徴兵画面で傭兵隊長と契約すると、兵を率いてすぐに加わります（8季・毎季給金。払えなければ去る）。AIも戦時に雇います。
- **迎撃**：攻め込まれた地方の隣の自領にいる武将は、自動で後詰めとして合戦に加わります（その地方に最低1人は残る）。

### 後宮・王族

- 上部の「後宮」から君主の妃を寵愛（一季に一人）すると子を授かりやすくなります。男子は15歳で一門の武将として出仕し、後継ぎ候補になります。
- 姫は15歳になると、他国の君主に嫁がせて**婚姻同盟**を結ぶか、家臣に嫁がせて忠誠を100（一門）にできます。
- 他国へ縁談を申し込んで姫を妃に迎えたり、AIから縁談が届いたりします。滅亡した国の姫を迎え入れることもできます。
- ボルテ、北条政子、ソルカクタニなど史実の人物も登場します。肖像は文化ごとの装い（モンゴルのボクタ冠など）をSVGで描いています。

### 宮廷（`src/game/court.js`）

- **妃の個性**：賢妃（正室なら家臣の忠誠の目標+3・不満をなだめる）、良妻、才媛（子の政治・魅力）、武門の娘（男子の武力・統率）、野心家（寵愛を得やすいが浪費や口出し）、嫉妬深い（揉め事）、温順。ボルテ＝良妻、北条政子＝賢妃など。
- **正室と側室**：正室の子は嫡子になります。正室を替えると、退けられた正室とその子・実家が不満を抱きます。
- **後継ぎ**：指名がなければ嫡子の年長が継ぎます。嫡子をさしおいて指名すると不満が出ます。代替わりのとき、不満を持つ男子（野心家、母が野心家、封地持ち、嫡子なのに外されたなど）が**跡目争い**で兵を挙げ、自立することがあります。史実の王子（ジョチ〜トルイ、源頼家・実朝など）は父母つきで登場します。
- **傅役と教育**：幼い男子・姫に傅役をつけ、武芸・学問・文武両道を選べます。毎年100金で傅役の能力に近づくように育ち、特技を受け継ぐこともあります。
- **封地**：成人した王族に首都以外の地方を封地として与えると太守になり、その都市の民忠の目標+6。
- **婚姻の重み**：婚姻同盟は冷え込みにくく、破ると信用をさらに失い、嫁いだ妃の寵愛も冷えます。他国出身の妃を寵愛すると実家との関係が良くなり、疎むと悪くなります。跡継ぎのいない国は、姫の嫁ぎ先の君主が**婚姻による相続**で継ぐことがあります。
- **後宮の出来事**：嫉妬による諍い、野心家の浪費や政への口出し、賢妃の内助の功、妃の死去。
- **妃の迎え方**：他国への縁談、AIからの縁談、国内の名家から（300金・候補は毎年入れ替わる）、家臣の娘を娶る（100金・年に一度。家臣は外戚となり忠誠の目標+12）、滅びた国の妃（未亡人）や姫を迎える。

### 技術者

文化圏ごとに得意分野の違う専門家（農業技師・牧夫・商人・工匠・建築家・攻城技師・学者・鍛冶師、Lv1〜3）が各地にいます。
自領か友好国（友好度20以上／条約国）にいる者を招聘し、都市に配置（1都市2人まで・毎季給金）すると箱庭の産出や訓練度などが上がります。攻城技師がいれば工房なしで攻城兵を徴兵できます。都市を奪われると技術者も奪われます。

### 技術者の成長と技術革新（`src/game/tech.js`・`src/game/research.js`）

- **成長**：仕えている技術者は毎年経験を積み、最大Lv5まで腕を上げます（師匠がいる都市、政治の高い太守のもとでは早く育つ）。技術者は太守の政治力も伸ばします。
- **個性**：名人（効果1.3倍）、師匠（周りが育つ）、発明家（研究1.5倍）、強欲（給金1.5倍・効果1.15倍・引き抜かれやすい）。
- **太守との相乗**：政治80以上の太守なら効果+10%、相性のよい特技（商人×商才、鍛冶師×練兵、建築家×築城など）なら+25%。
- **招聘と引き抜き**：他国にいる技術者は名声と友好度しだいで断ることがあります。他国に仕える技術者も、招聘費の2倍で引き抜けます（関係は悪化）。
- **技術革新**：「研究」で国の技術を選び、技術者の研究点で獲得します。紙幣・カナート・合成弓の改良・重装騎兵の鎧・築城術・回回砲・火薬（震天雷）・羅針盤・印刷術・駅伝制（ジャム）。発祥の文化圏や、隣国が持つ技術は安く習得でき、征服や交易で学び取ることもあります。
- **伝播**：遊牧の征服者は攻め取った都市の職人を連れ帰ることがあり、交易相手の職人が移り住むこともあります。
- 配置した技術者は箱庭の宮殿の前に姿を見せます。

### 特産品交易

- 各都市は特産品（絹・香辛料・毛皮・陶磁器など37種）を生産・備蓄します。相場は産地から遠いほど高く、季節ごとに変動します。
- 隊商宿のある都市から「交易・隊商」で交易路を開くと、毎季、特産品を運んで売り、帰りに相手の特産品を仕入れて戻ります。本数・積荷・最大距離は隊商宿のレベルで決まります。
- 敵地を通ると略奪の危険。他国の都市では関税（10%）がかかり、その国との友好度が少しずつ上がります。珍しい輸入品は民忠を高めます。
- 地図には自国の交易路が金色の点線で描かれ、駱駝の隊商が行き来します。AIの国も交易路を開きます。

### 外交

- **宣戦と参戦**：他国を攻めると宣戦布告になり、相手の同盟国・従属国が参戦してきます。自国の同盟国が攻められたときは参戦を求められます。
- **援軍**：同盟国・宗主・従属国の武将は、隣接する地方での合戦に援軍として加わります（「援」の印）。
- **和平交渉**：白紙講和・賠償金の支払い／要求・地方の割譲・従属の要求から条件を選べます。戦況（兵力比・奪った地方）と戦争の長さで受諾率が変わります。
- **従属と朝貢**：強国に臣従する／弱国に従属を要求する／独立を宣言する。従属国は毎季収入の20%を朝貢し、宗主の戦争に参戦します。長く従えば併合できます。
- **包囲網**：一国が強くなりすぎると（全地方の2割以上・2位の1.6倍以上の国力）、周辺国が同盟を結んで対抗します。
- 友好度は季節ごとに少しずつ変化し、AIも講和・降伏・臣従の要求を持ちかけてきます。

### 外交の奥行き（`src/game/statecraft.js`）

- **君主の気質**：君主の特技と好戦度から、信義に厚い・背信の気あり・策謀家・温厚・好戦的・慎重・実利を重んじる、のいずれかになります。受諾率が変わり、背信の君主は有利と見れば条約を破って攻めてきます。温厚な国は贈物の使者を送ってきます。
- **因縁**：史実の宿敵（キヤトとタタル、金と南宋、アイユーブ朝と十字軍諸国など）は関係が悪く、交渉にも応じにくい。同じ文化の国（同族）は応じやすく、寛容でない異教どうしは応じにくくなります。
- **信用**：条約を破ると大きく下がり（同盟-25・停戦-15）、参戦要請に応じたり和平を守ったりすると上がります。信用はすべての国の受諾率に影響し、時間とともに60へ戻ります。
- **人質**：同盟・停戦を申し込むときに武将を人質として添えると受諾されやすくなります（一門ほど効果大）。人質は相手の首都にとどまり、条約を破った側の人質は処断され、条約が切れれば帰国します。
- **通商条約**：互いの関税がなくなり、交易の利益+10%、友好度が毎季上がります。戦争で解消されます。
- **朝貢**：強国は弱国に朝貢を要求できます。朝貢国は毎季収入の10%を納め、互いに攻め込めなくなります（従属と違い参戦の義務はない）。力をつけた朝貢国はやめることもあります。
- **取引**：金・馬・地方（相手と接する首都以外）を組み合わせて交換を持ちかけられます。相手の気質（策謀家は強欲）や因縁で評価が変わります。
- **外交イベント**：贈物の使者、通商の申し入れ、大ハーン（即位したモンゴル）や覇権国からの朝貢の要求、覇権国に対抗する国々の**会盟**（参加国が一斉に同盟を結び、プレイヤーも招かれる）。

### 籠城戦・天候・計略

- **強襲か包囲か**：城壁のある都市を攻めるとき、すぐに城攻めの合戦をするか、包囲して兵糧攻めにするかを選べます。
- **包囲**：城内の兵糧（城壁と農地の数で決まる）が毎季減り、尽きると城兵は飢え、2季後に開城します。包囲軍は毎季城壁を削り（攻城兵は大きく削る）、いつでも「総攻撃」をかけられます。包囲された都市は収入が大きく減り、徴兵できません。
- **出撃と後詰め**：守備側は城から打って出て包囲軍と野戦でき、隣の自領からの救援（後詰め）でも包囲を破れます。
- **兵站と冬**：包囲軍は兵糧を倍消費し、兵糧が尽きると兵が逃げます。冬は包囲軍が大きく消耗し、冬の遠征では遊牧民以外の兵が凍傷で減ります。
- **天候**：晴れ・雨（弓と火計が弱い）・雪（移動力-1、遊牧民以外は士気低下）・霧（射程-1）・酷暑（攻撃側の士気低下）。
- **総大将（★）**：君主か最も統率の高い武将。敗走すると全軍の士気が大きく下がり、総崩れになることがあります。
- **計略**：政治力に応じた回数だけ、攻撃の代わりに使えます。火計（森・城の敵に大きな効果）、偽報（敵の次の手番を封じる）、鼓舞（周囲の士気回復）。
- **伏兵**：森に布陣した部隊は敵から見えず、奇襲すると大きな損害を与えます。
- **地形**：森・丘・城は守りに有利、川は不利。丘の上から攻めると+20%（弓は+15%・射程+1）、坂の下から攻め上がると-15%で突撃も弱まります。川の中からの攻撃は-30%、渡河した直後は-15%。草原では騎馬の攻撃+15%、森では騎馬の白兵-25%（守りも弱い）、山岳では騎馬の白兵-10%。山岳・森林の地方では歩兵の白兵が+10%、歩兵は森・丘で守りも堅くなります。山岳へ攻め込むと行軍で兵の3〜4%を失い、夏の砂漠はイスラーム・インド圏以外の軍の兵を5%奪います。合戦中に敵へカーソルを合わせると、補正の内訳が表示されます。
- **討死・負傷**：部隊が敗走すると、武将は討死・負傷（2〜4季出陣できない）・無事のいずれかになります。武力が高いほど生き延びやすくなります。設定で「君主の保護」をオンにすると、自分の君主は討死せず負傷にとどまります。君主が出陣するときは警告が出ます。
- **一騎討ち**：武力70以上の武将は隣接する敵将に一騎討ちを挑めます（3本先取）。格下の相手は断ることがあり、断ると士気が下がります。敗者は討死・負傷・逃走のいずれか。勝者の軍は士気が上がります。

### 人事（`src/game/personnel.js`）

太守の政治力で産出と建設速度が、魅力で民忠が上がります。在野の人材の登用や人材探索もできます。武将は年を取り、やがて世を去ります（15歳で元服して出仕）。上部の「家臣」で家臣団の一覧・役職・特技を確認できます。

- **特技**：騎射・突撃・鉄壁・築城・豪傑・智謀・練兵・仁政・商才・弁舌・忠義・野心。史実の人物には固有の特技があります（ジェベ＝騎射・突撃、耶律楚材＝仁政・商才、ジャムカ＝野心など）。
- **功績と位階**：合戦（勝利・総大将・一騎討ちの勝利）、内政命令、調略の成功で功績が貯まり、無位→十人長→百人長→千人長→万人長と昇進させられます（恩賞の金が必要）。位階ごとに率いる兵の上限+5%。功績が届いたのに昇進させないと不満を持ちます。
- **成長と衰え**：合戦や内政で使った能力は経験を積んで伸びます（若いほど伸びやすい）。60歳を過ぎると武力・統率が衰えます。
- **役職**：宰相（全都市の金+）、軍師（出陣した合戦で伏兵を見破り、計略の成功率+10%）、大将軍（出陣した合戦で全軍の士気+10）。兼任はできず、AIも毎年任命します。
- **忠誠**：毎季、目標値（君主の魅力・君主との相性◎〜×・位階・役職・特技・昇進の遅れ・俸給の遅れで決まる）へ近づきます。35未満で出奔することがあります。
- **謀反**：忠誠を大きく失った太守（野心家は40未満）は、地方ごと謀反を起こして自立します。
- **調略**：隣接する敵地の武将を、使者（魅力・弁舌）を送って誘います。「引き抜き」はすぐに兵の半分を連れて寝返り、「内応」は2年以内の合戦で戦場で寝返ります。AIも不満を抱えた武将を狙って調略してきます。
- 贈物で友好度を上げ、同盟・停戦を結べます。

### 人材と登用（`src/game/talent.js`）

- **名声**：領地の数・君主の魅力・信用などで決まり、登用の成否や在野の人物の集まりやすさに影響します。
- **口説き方**：登用のとき贈物（100〜500金）を添えたり、位階を約束したり（一つ上の位階で迎える）できます。断られても季節を改めて通い続けると応じやすくなります（三顧の礼）。
- **在野の放浪と仕官**：在野の人物は各地を渡り歩き（名声の高い国の方へ）、その地の支配者に自ら仕官を願い出ることがあります。
- **推挙**：魅力の高い家臣や弁舌の家臣が、毎年知人を推挙することがあります（その国には仕えやすい）。
- **史実の在野人物**：チンカイ、マフムード・ヤラワチ、郭宝玉、史天沢、北条泰時、ナスィールッディーン・トゥースィーなどが、その時代になると在野として現れます。
- **俸給**：家臣には毎季、5金＋位階×4金の俸給がかかります（君主と傭兵を除く）。

### 軍師（`src/game/strategist.js`）

- **見立て**：成功率は数字では表示されません。軍師がいると、外交・縁談・登用・捕虜の登用・調略・布教・計略・一騎討ちなどの見込みを「まず間違いございません／うまくいくでしょう／五分五分かと／難しいでしょう／まず無理かと」の言葉で助言します。軍師の政治力が低いと見立てが外れることがあり、合戦では軍師が同じ戦場にいると正確になります。交易路の危険も「安全／やや危険／危険」で示します。
- **謀略の察知**：敵の調略を軍師が見破ることがあります。引き抜きは未然に防ぎ、内応の約束は「内通」として露見します（家臣団で詰問・追放）。仕掛ける側の軍師が優れていると見破られにくくなります。
- **離間の計**：外交画面から、二国の間に偽りの噂を流して仲を裂きます。友好度が大きく下がり、同盟・停戦が決裂することもあります。
- **流言**：隣接する敵の都市に流言を放ち、民忠と治安を下げます。
- **助言**：毎季、地図の左上で、謀反・出奔のおそれ、侵攻の気配、攻めどき、洪水・治安・民忠・兵糧の不安などを知らせます。政治力が高いほど多くのことに気づきます。
- 離間の計と流言は軍師自身が行うため、その季節は出陣できません。軍師は合戦でも伏兵を見破り、計略の成功率を上げます。AIの軍師も調略の察知・離間・流言を行います。

## 構成

```
src/
  game/      ゲームロジック（描画から独立・テスト可能）
    data.js      地方・勢力・武将・建物・兵種の定義
    geo.js       地図の投影、ボロノイ分割による地方領域・隣接・標高
    state.js     新規ゲーム生成と共通ヘルパー、セーブ／ロード
    city.js      箱庭（都市グリッド・建設・産出計算・AIの都市開発）
    battle.js    ヘックス戦術戦闘エンジン（AIも同じ規則で戦う）
    military.js  徴兵・占領・戦後処理・捕虜・継承・滅亡
    diplomacy.js 贈物・同盟・停戦
    ai.js        勢力AI（内政・徴兵・侵攻・増援）
    turn.js      ターン進行・季節の経済・年次イベント・勝敗判定
    royal.js     後宮・王族（妃・誕生・婚姻・縁談）
    tech.js      技術者（招聘・配置・効果）
    trade.js     特産品の生産・相場・交易路
    scenarios.js シナリオ（開始年・版図・君主・史実の没年など）
    events.js    史実イベント（条件・選択肢・効果）
    siege.js     籠城戦（包囲・兵糧・城壁・総攻撃・出撃・後詰め）
    admin.js     内政（税率・治安・治水・商業・信仰と文化・内政命令）
    personnel.js 人事（特技・功績と位階・役職・忠誠と相性・調略・謀反）
    strategist.js 軍師（見立て・謀略の察知・離間の計・流言・助言）
    statecraft.js 外交の奥行き（気質・因縁・信用・人質・通商・朝貢・取引・会盟）
    warfare.js   軍事の拡張（固有兵種・陣形・遠征・渡海・補給線・疲労・傭兵）
    court.js     宮廷（妃の個性・正室と嫡子・後継ぎと跡目争い・傅役と教育・封地・婚姻の相続）
    talent.js    人材（名声・登用の口説き方・放浪と仕官・推挙・史実の在野人物・俸給）
    research.js  技術革新（研究・国の技術・伝播）
  render/    Three.js の描画（世界地図・箱庭・合戦・ローポリモデル）
  audio/     WebAudio による手続き生成の音楽・効果音
  ui/        HTML オーバーレイの UI とダイアログ
tests/       vitest によるロジックのテスト（60ターンの全自動シミュレーションを含む）
```

セーブデータはブラウザの localStorage に保存されます（毎ターン自動保存＋3スロット）。
